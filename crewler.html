Learn Web Crawling with Python

Discover how programs visit pages, find links, and collect information.

1. What Is a Web Crawler?

A web crawler is a computer program that automatically visits web pages and collects information from them.

Imagine opening a website, reading its page, clicking a link, reading the next page, and repeating those actions. A crawler performs a similar process automatically, following rules written by its programmer.

Crawlers are used by search engines, research tools, website monitoring systems, and data collection applications.

Example

Imagine a website about artificial intelligence with pages about Python, neural networks, and tokenizers. A crawler could visit the home page, find links to those topics, and collect their titles.

Simple definition: A crawler discovers pages and visits them automatically. A scraper is a program that extracts specific information from a page. One program can do both jobs.

2. How Does a Crawler Work?

Step 1: Start with a URL

A URL is a web address, such as https://example.com/. The crawler needs a starting address so it knows where to begin.

Step 2: Put the URL in a queue

A queue is a collection of tasks waiting to be processed. The crawler places the starting URL in its queue.

Step 3: Visit a page

The crawler requests a page and receives its response. For a real website, this requires an HTTP request and a successful response from the server.

Step 4: Read the page

A crawler can examine the page's HTML, which describes its structure. It may extract the page title, headings, text, and links.

Step 5: Discover links

If the page links to other pages, the crawler can add those URLs to its queue. It should check whether each URL has already been visited to avoid repeating work.

Step 6: Repeat within limits

The crawler repeats the process until the queue is empty or a limit is reached. Limits help control how many pages it visits and how much time and memory it uses.

The crawler cycle:

Starting URL → Queue → Visit page → Extract information → Find links → Repeat

3. A Simple Python Crawler

Before connecting to the internet, let's build a small crawler that operates on sample pages stored in Python.

This lets you understand the crawler's queue, visited-page tracking, link discovery, and page limits without sending requests to external websites. 

from collections import deque

pages = {
    "home": {
        "title": "MyAIBrain Home",
        "links": ["python", "ai"]
    },
    "python": {
        "title": "Learn Python",
        "links": ["neural"]
    },
    "ai": {
        "title": "Introduction to AI",
        "links": ["neural"]
    },
    "neural": {
        "title": "Neural Networks",
        "links": []
    }
}

def crawl(start_url, max_pages=10):
    queue = deque([start_url])
    visited = set()

    while queue and len(visited) < max_pages:
        url = queue.popleft()

        if url in visited:
            continue

        if url not in pages:
            continue

        visited.add(url)
        page = pages[url]

        print("Visited:", url)
        print("Title:", page["title"])

        for link in page["links"]:
            if link not in visited:
                queue.append(link)

        print()

crawl("home")

What does each part do?

from collections import deque imports a queue structure. A queue lets the crawler process pages in the order they were discovered.

pages represents a tiny website. Each entry has a title and a list of links. These are sample data, not actual internet pages.

queue = deque([start_url]) adds the first page to the queue. The crawler starts with the page named home.

visited = set() creates an empty set for pages already visited. A set helps the crawler avoid processing the same page again and again.

while queue repeats the process while pages remain waiting in the queue. The maximum-page condition prevents the crawler from exceeding its configured limit.

queue.popleft() removes the next URL from the front of the queue.

page["title"] retrieves the title from the sample page, and page["links"] retrieves its outgoing links.

Finally, the crawler adds newly discovered links to the queue. If two pages link to the same destination, the visited set helps prevent duplicate visits.

Important: This first example is a simulated crawler. It does not download web pages. It teaches the core crawling algorithm before we add real HTTP requests and HTML parsing.

5. How to Crawl Real Websites

A real crawler needs to request web pages over HTTP, examine the returned HTML, extract links, and convert relative links into complete URLs.

Python libraries such as requests and BeautifulSoup are commonly used for these tasks. The browser playground above does not install or use those libraries; it runs the simulated crawler only.

Important rules for real crawlers

  • Check a website's terms and crawling policies.
  • Respect its robots.txt guidance.
  • Make requests slowly and avoid overloading servers.
  • Use page limits and timeouts.
  • Do not attempt to bypass logins, access controls, or blocks.
  • Collect only information you have a legitimate reason to use.

What is robots.txt?

A website may publish a file at a path such as /robots.txt. It gives automated crawlers guidance about which parts of the site the site owner requests they should or should not crawl.

It is crawler guidance, not a way to grant access to private information or override a website's terms and security controls.
