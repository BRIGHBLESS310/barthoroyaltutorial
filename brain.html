Welcome to Python!

Python is a programming language used to build websites, automate tasks, analyze data, and create AI models.

You do not need to know everything at once. Read a lesson, try the code, and experiment.

Our goal: Learn the Python basics before moving to neural networks, tokenizers, and MyAIBrain.

Python Basics

1. Print

Display text and results on the screen.

print("Hello!")

2. Variables

Store information using variable names.

name = "Alex"
print(name)

3. Mathematics

Add, subtract, multiply, and divide numbers.

print(10 + 5)

4. Conditions

Make decisions using if and else.

if 10 > 5:
    print("Yes")

5. Loops

Repeat instructions automatically.

for i in range(3):
    print(i)

6. Functions

Organize reusable pieces of code.

def greet():
    print("Hello!")

7. Lists

Store several values in one collection.

names = ["Ada", "Sam"]
print(names[0])

8. User Input

Learn how programs receive information.

name = input("Name: ")
print(name)

9. Dictionaries

Store information using keys and values.

person = {"name": "Ada"}
print(person["name"])

Practice Challenges

Try these challenges by writing code in the editor.

  1. Print your name on the screen.
  2. Create two number variables and print their sum.
  3. Use an if statement to check whether a number is positive.
  4. Use a loop to print numbers from 1 to 10.
  5. Write a function that adds two numbers.
  6. Create a list of five favourite foods and print each item.
  7. Create a dictionary containing a person's name and age.

Run Python on Your Computer

  1. Install Python from the official Python website.
  2. Open VS Code and create a file named first_program.py.
  3. Write your Python code and save it.
  4. Open the VS Code terminal.
  5. Run the command below.
python first_program.py

If the command does not work on Windows, try py first_program.py.
