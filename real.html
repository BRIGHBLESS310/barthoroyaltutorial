Build a Real AI From Scratch

Learn how to create, train, and use your own neural network.

Welcome to the real AI course

In this course, we will build MyAIBrain step by step. We will write our own tokenizer, neural network, training loop, and text generator using Python and PyTorch.

We will begin with a tiny model so beginners can understand how learning works before moving on to a Transformer.

Important: This first model will learn only simple patterns from a small text file. It will not immediately have the knowledge or abilities of ChatGPT.

Our learning plan

  1. Prepare training text.
  2. Convert characters into token IDs.
  3. Create a neural network with PyTorch.
  4. Train it by minimizing prediction errors.
  5. Generate text using its learned weights.
  6. Upgrade the model to use a Transformer.

Lesson 1: Prepare your computer

We will run the actual AI in Python on your computer. The website explains the code, while Python and PyTorch do the model training.

Step 1: Open your project

Open your existing MyAIBrain folder in VS Code. Do not delete your existing checkpoints or replace your current model files. We will use a separate folder for this new experiment.

Step 2: Open the VS Code terminal

Select Terminal, then New Terminal. Enter these commands in PowerShell from your MyAIBrain project folder: 

mkdir real_ai_course
cd real_ai_course
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install torch

If PowerShell blocks activation, use the Python executable directly with .\.venv\Scripts\python.exe. You can then install PyTorch using that executable.

Keep your existing project environment unchanged. Installing PyTorch in this new environment keeps the experiment separate from your earlier work.

Step 3: Check PyTorch

Create a file named check_torch.py in the new folder and add: 

import torch

print("PyTorch version:", torch.__version__)
print("AI training device: CPU")
print("PyTorch is ready!")

Run it from the terminal:

python check_torch.py

If you see the PyTorch version and "PyTorch is ready!", your environment is ready for the next lesson.

Try It Yourself

This small browser exercise demonstrates the basic training idea: compare a prediction with the correct answer, calculate the error, and adjust a number to reduce that error.

It is a learning illustration, not the full PyTorch language model. We will train the actual neural network on your computer in the next coding step.

Change the values and perform a learning step.

What did you learn?

A trainable neural network uses a loss function to measure prediction error. An optimizer uses gradients to adjust the network's weights so that the loss can decrease. Real training repeats this process across many examples.
