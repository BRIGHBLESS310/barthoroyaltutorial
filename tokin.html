Build Your Own Tokenizer

Learn how AI turns text into numbers.

1. What is a tokenizer?

A tokenizer is a program that breaks text into tokens and converts those tokens into numerical IDs. Neural networks use these numbers as input.

For example:

Text: My AI learns!

Tokens: my | ai | learns | !

IDs: 2 | 3 | 4 | 5

These IDs are only an illustration. The actual IDs depend on the vocabulary built by the tokenizer. The numbers themselves do not contain the meaning of the words.

2. How does a tokenizer work?

  1. Normalize: Clean or standardize the text. This example converts text to lowercase.
  2. Split: Separate words and punctuation.
  3. Build vocabulary: Give each known token a unique number.
  4. Encode: Replace tokens with their IDs.
  5. Decode: Convert IDs back into tokens and reconstruct the text.

4. Understand the code


            
The vocabulary

            

                A vocabulary is a collection of known tokens.
                Each token gets a unique ID. This example reserves
                ID 0 for padding and ID 1 for unknown tokens.
            


            
Token splitting

            

                The program separates words and punctuation.
                For example, "learn!" becomes "learn" and "!".
                It converts everything to lowercase, so the original
                capitalization is not preserved.
            


            
Encoding

            

                Encoding looks up each token in the vocabulary and
                returns its number. If a token is not in the vocabulary,
                it receives the unknown-token ID.
            


            
Decoding

            

                Decoding looks up each number and converts it back
                to a token. A real tokenizer has additional rules
                to reconstruct spaces, punctuation, and subword pieces.
            


            
5. What are unknown tokens?


            

                If you type a word that was not in the training text,
                this simple tokenizer uses the special token
                [UNK]. For example, try adding a new word
                to your input without adding it to the training text.
            


            

                Modern subword tokenizers can often represent unfamiliar
                words as smaller pieces instead of replacing the whole
                word with one unknown token.
            


            
6. Is this the tokenizer used by ChatGPT?


            

                No. This is a beginner's word-level tokenizer.
                Modern language models generally use more sophisticated
                tokenization algorithms, often based on subwords.
            


            

                The important idea is the same: convert text into
                token IDs that match the model's vocabulary.
                During generation, the model produces token IDs
                that are converted back into text.
