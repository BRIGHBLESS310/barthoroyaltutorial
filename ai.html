Creating Your First AI Brain

First, create a file called first_brain.py. This simple program responds to questions using predefined rules. 

print("Hello, World!")
print("Welcome to AI!")
print("This is my first AI brain!")

Save the file and run it in your terminal:

python first_brain.py

Try It Yourself: Build a Tiny AI Brain

Edit the Python code, click Run AI Brain, and then ask your chatbot questions below.

How it works: You write the chatbot's rules in Python. The browser runs your code, and the chat box sends your questions to it.

How to Teach Your AI a New Answer

Add another rule inside the answer() function. For example, insert this before the final else: 

elif question == "what is python?":
    return "Python is a programming language."

Click Run AI Brain again to load your changes, then ask: What is Python?
