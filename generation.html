How AI Generates Text

Learn how an AI predicts what to write next.

1. What is AI text generation?

AI text generation is the process of using an artificial intelligence model to produce text, such as answers, stories, explanations, and conversations.

Many modern AI chatbots use a neural network called a Transformer. During training, the model learns patterns from large amounts of text. When someone gives it a prompt, the model uses those learned patterns to predict what token should come next.

2. How does it work?

  1. Prompt: You type something, such as "Artificial intelligence".
  2. Tokenization: The text is divided into tokens. Tokens may be whole words, word parts, or punctuation.
  3. Neural network: The model processes the tokens and calculates possible next tokens.
  4. Prediction: The model selects a next token based on its predicted probabilities and its generation settings.
  5. Repeat: The selected token is added to the text. The model predicts another token, again and again, until it reaches a stopping condition.

Example

Prompt: The sun rises in the ...

Possible next token: east

The model adds "east" and can continue predicting more tokens if needed.

3. What is a token?

A token is a unit of text that the AI reads or generates. A tokenizer converts text into token IDs that the model can process.

A real tokenizer might split the same sentence differently and convert each token into a number.

6. How real AI is different

A real language model uses neural network weights to calculate scores or probabilities for possible next tokens. It can use the surrounding context rather than relying on a fixed dictionary of word connections.

The training process adjusts the model's weights so that it becomes better at predicting tokens from training examples. During text generation, the model repeatedly predicts and adds tokens to its response.
